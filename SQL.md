# SQL для системного аналитика
## Зачем системному аналитику знать SQL?
SQL – это ключевой инструмент для работы с базами данных. Системный аналитик должен уметь:
✔ Анализировать данные в базе (SELECT, фильтрация, сортировка)
✔ Объединять данные из нескольких таблиц (JOIN)
✔ Группировать и агрегировать данные (GROUP BY, COUNT, SUM)
✔ Проверять корректность данных в системе
✔ Подготавливать тестовые сценарии, используя SQL-запросы
✔ Понимать архитектуру базы данных и взаимодействие сервисов
