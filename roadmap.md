# roadmap для основы системного анализа

- SQL – изучение основ запросов (SELECT, JOIN, GROUP BY)
- Базы данных – нормализация, индексы, реляционные БД
- Системный анализ – основы анализа, бизнес-процессы
- UML/BPMN – диаграммы Use Case, Activity, Sequence
- API и интеграции – REST, SOAP, gRPC, работа с Postman
- Документы – написание SRS, API спецификаций, User Stories
- Тестирование – основные виды тестирования, чек-листы
- Инструменты – Jira, Confluence, Miro, Draw.io
- Практика – разбор кейсов, задачи, участие в проектах
